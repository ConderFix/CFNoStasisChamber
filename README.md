Эта система исправит такой багоюз как EnderPearl Statis Chamber. Задача плагина удалить эндер-жемчуг через 25 секунд (настраивается в конфиге) после его появления.

Конфиг:
```yaml
# Эта функция отвечает за то, через какое время удалится эндер-перл после его появления.
time-before-remove: 25
```
